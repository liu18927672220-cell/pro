# نظام علبة الدواء الذكية | Smart Medicine Box

> **مشروع تخرج - قسم هندسة تقنيات الأجهزة الطبية (Medical Technology Engineering Graduation Project)**  
> منصة ويب تفاعلية وتطبيق هاتف لإدارة ومراقبة مواعيد تناول الأدوية، مع الفتح التلقائي للحجرات، التنبيه الصوتي الحاد، اهتزاز الجوال، وتأكيد تناول الجرعة بالتقاط صورة للدواء عبر الكاميرا.

---

## 🌟 مميزات المشروع (Key Features)

1. **لوحة تحكم طبية متقدمة (Dark Mode Medical Dashboard):**
   - متابعة حية لحالة اتصال الجهاز والبطارية وقوة إشارة الواي فاي.
   - متابعة 4 حجرات أدوية مستقلة مع عدّاد الحبوب المتبقية وشريط التنبيه عند اقتراب النفاد.
   - إمكانية التحكم والفتح/الإغلاق اليدوي بضغطة زر.

2. **الفتح التلقائي للحجرات (Automated Chamber Dispensing):**
   - يعمل بجدولي مهام خلفي (`APScheduler`) يفحص المواعيد كل دقيقة.
   - عند حلول موعد الجرعة المجدول، تُفتح الحجرة المحددة تلقائياً.
   - مهلة أمان (5 دقائق): إذا لم تُؤخذ الجرعة، يُسجّل إنذار جرعة فائتة وتُغلق الحجرة لحماية الدواء.

3. **إنذار صوتي إسعافي واهتزاز متواصل للجوال (Loud Alarm & Mobile Vibration):**
   - مولّد صفارة إنذار طبية عالية عبر تقنية `Web Audio API` لا تتوقف تلقائياً.
   - اهتزاز متواصل لشاشة الجوال عبر `Web Vibration API`.
   - شاشة طوارئ حمراء تمنع تجاهل الموعد وتلزم المريض بالاستجابة الفورية.

4. **تأكيد تناول الدواء بالصورة (Mandatory Pill Photo Confirmation):**
   - فتح الكاميرا فوراً لإلزام المريض أو الممرض بالتقاط صورة للدواء/الحبة.
   - لن يتوقف الصوت والاهتزاز حتى يتم تصوير الدواء وإرساله بنجاح!
   - حفظ الصور في مجلد خاص مع توثيق التوقيت ورقم الحجرة واسم الدواء.

5. **جدول مواعيد الأدوية والجرعات (Medication Scheduler):**
   - إضافة وحذف الأدوية وتحديد الحجرة والجرعة ومواعيد اليوم وأيام الأسبوع.
   - خط زمني تفاعلي (Daily Timeline) لعرض مواعيد جرعات اليوم بالتسلسل.

6. **سجل الأحداث والإنذارات (Event Logs & Audit Trail):**
   - توثيق دقيق لكل عملية فتح وإغلاق، نجاح أخذ الجرعة، تحذيرات النفاد، والإنذارات الطبية مع صور مصغّرة للتأكيدات وفلاتر بحث.

7. **تطبيق ويب تقدمي للجوال (PWA Ready):**
   - ملف `manifest.json` وتصميم متجاوب 100% يتيح تثبيت الموقع كأيقونة تطبيق جوال مستقل على الهواتف الذكية.

## 🏗️ هيكلية المشروع (Project Structure)

```
smart-medicine-box/
├── server.py                 # الخادم الخلفي (Flask + APScheduler + REST APIs)
├── requirements.txt          # مكتبات بايثون المطلوبة
├── README.md                 # دليل المشروع والتوثيق
├── .gitignore                # استثناء الملفات المؤقتة
├── templates/
│   ├── base.html             # القالب الأساسي وشريط التنقل وشاشة إنذار الطوارئ
│   ├── index.html            # لوحة القيادة وحجرات الأدوية وشريط اختبار الجوال
│   ├── schedule.html         # صفحة جدول المواعيد ونافذة إضافة دواء
│   ├── logs.html             # صفحة سجل الأحداث والإنذارات
│   └── confirmations.html    # معرض صور تأكيدات الجرعات الملتقطة بالكاميرا
└── static/
    ├── style.css             # التنسيقات الطبية وتأثيرات الإنذار والأنيميشن
    ├── script.js             # التفاعل ومولد الصوت والاهتزاز ونظام الكاميرا
    ├── manifest.json         # تعريف التطبيق للجوال (PWA)
    └── confirmations/        # مجلد تخزين صور تأكيدات الأدوية
```

## 🚀 طريقة التثبيت والتشغيل (How to Run)

### 1. تثبيت المتطلبات
```bash
pip install -r requirements.txt
```

### 2. تشغيل الخادم
```bash
python server.py
```

### 3. فتح التطبيق
* **على الكمبيوتر:** افتح المتصفح على: `http://127.0.0.1:5000`
* **على الجوال:** اتصل بنفس شبكة الواي فاي وافتح عنوان الـ IP المحلي لجهازك، مثلاً: `http://192.168.0.43:5000`
* **لتثبيته على الجوال:** اضغط على خيارات المتصفح (⋮) ثم **"إضافة إلى الشاشة الرئيسية (Add to Home Screen)"**.

## 🧪 واجهات الـ API المتاحة (REST Endpoints)

| المسار | الطريقة | الوظيفة |
|--------|---------|---------|
| `/api/status` | GET | الحصول على الحالة العامة للجهاز والحجرات والإنذار النشط |
| `/api/chamber/<id>/toggle` | POST | فتح أو إغلاق الحجرة يدوياً |
| `/api/chamber/<id>/taken` | POST | تأكيد أخذ الدواء وتخزين صورة الكاميرا وإيقاف الإنذار |
| `/api/schedule/add` | POST | إضافة موعد دواء جديد |
| `/api/schedule/delete/<id>` | DELETE | حذف موعد دواء |
| `/api/alarm/trigger-test` | POST | تفعيل فوري لصفارة الإنذار واهتزاز الجوال للاختبار |
| `/api/confirmations` | GET | استعراض سجل صور التأكيد |
| `/api/logs` | GET | استعراض سجل الأحداث والإنذارات |
